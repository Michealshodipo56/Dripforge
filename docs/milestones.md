# Milestones and acceptance gates

## 1 — Foundation
Real user auth, GitHub App connections, issue synchronization, provider adapters, encrypted credentials, models, database and usable dashboard.

## 2 — Runtime
Durable jobs, isolated workers, command execution, file operations, live logs, cancellation and crash recovery.

## 3 — Issue automation
Issue investigation, scoped code changes, real validation, Git commits, fork-aware PR creation and audit evidence.

## 4 — CI repair
Webhook/polling reconciliation, failed-check log retrieval, bounded repair attempts, same-branch PR updates and review feedback handling.

## 5 — Optimization
Targeted retrieval, repository cache, accurate usage accounting, budget enforcement, and model routing.

## 6 — Hardening
Least-privilege deployment, integration tests, production monitoring, responsive UI and operational runbooks.

## Definition of done
A connected account can select an actual assigned issue and produce a PR from real sandbox execution. Required checks pass, or the job records a truthful blocker. Every significant change has tests and meaningful commits. Target: **at least 101 meaningful commits** across implementation.
